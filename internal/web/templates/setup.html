Setup in the browser needs setup sessions in the daemon, which this version does not offer yet. Run the same assistant in a terminal:

open-conduit init --with claude

It starts Claude Code with the setup playbook in this folder. It asks before it writes the config, and open-conduit config validate and open-conduit doctor check the result. To change one value by hand, use open-conduit config set.

The quick start covers setting up with Claude or by hand.
