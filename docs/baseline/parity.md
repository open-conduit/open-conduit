## Intentional replacements, gaps and next decisions

- X01: Issue/PR/status/session/project structures in `internal/core/types.go`, `internal/store/store.go` and `internal/adapter/adapter.go` are source outcomes to translate, not new public types. Work owns lifecycle; labels/transitions are projections. Sessions/handoff stay executor-private; resources are optional. Resolve status/outcome mapping in 01-02 and dependent-correlation ownership in 01-04.
- X02: Old JSON persistence, process-handle claims and separate job/turn histories cannot satisfy the required atomic storage/leases/unified Execution design. 01-02/01-06 establish reference conformance first; 02-01/02-04/02-08 implement it. Source adoption is behavior evidence, not sufficient lease fencing.
- X03: `internal/core/wait.go` enums/hold markers move to adapter translation; generic waits match routed Events. Cross-work PR/issue/job dependencies must attach correlations explicitly (01-04/03-04). No bypass wake API or tracker state branch in core.
- X04: `README.md:Jobs on webhooks` says webhook jobs are not replayed on reconcile. A generic one-shot POST has no recoverable backing state. In 01-03/05-01 classify each event family (push/release/workflow_run/custom POST) by actual readable source history, not adapter-wide assumption. Reconstruct where possible; declare non-re-derivable exceptions otherwise, retain markers for ambiguous non-repeatable writes. No silent promise of lossless arbitrary POSTs.
- X05: Sweep, triage, host watch and quality/handoff metrics move out of the runtime. No Effect, DAG, workflow language, remote management or third-party manifest is introduced. See the package decision for deferred contracts.
- G01: Installed accounts and running deployment are not inferred from shipped code; confirmation belongs to 03-07/06-01 before switches. Each gate records observation period, thresholds, rollback triggers and single-owner proof. No production config or secret values were read for this baseline.
- G02: Source lacks focused proof for restart adoption, several CLI flows, tunnel/PostHog behavior, full handoff feedback and crash atomicity. Assigned scenarios above must be implemented; source test names alone are never pass evidence. Real multi-day Slack wait cannot be replaced by accelerated CI.
- G03: No concrete blocker or unsupported required outcome found that warrants changing the PRD. Implementation differences alone do not justify adjustment. If a blocker appears, record workflow, source evidence and smallest proposed change, then update contracts and affected tickets before implementation.
